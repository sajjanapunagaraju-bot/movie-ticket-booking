# Online Movie Ticket Booking System

Full-stack Spring Boot + MySQL + Thymeleaf web application with separate User and Theatre Management (`@movie.com`) panels.

## Run in VS Code or IntelliJ IDEA
1. Ensure MySQL Server is running and update `spring.datasource.password` in `src/main/resources/application.properties`.
2. In VS Code, install **Extension Pack for Java** and **Spring Boot Extension Pack**, then open `Movie-Ticket-Booking-System`.
3. Run `MovieTicketApplication.java` or execute `mvn spring-boot:run` in the terminal.
4. Open `http://localhost:8080`.
